External Neko SDK header

The third-party l4n_plugin.h header is not included in this repository.
Before building, obtain it from your legitimate Neko installation/package and
place it at sdk/l4n_plugin.h. Use the SDK version supplied with Neko 2.51.0
(IL4NPlugin V2). Follow the original provider's terms.

Build from the x86 Native Tools Command Prompt for Visual Studio 2022 by running
build.cmd, or use an MSVC x86 CMake configuration. Build outputs are local files
and are not part of the uploaded source tree.
